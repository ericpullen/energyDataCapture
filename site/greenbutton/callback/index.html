Why this page exists

energycap runs on a machine inside the home, which has no public address. The utility needs a public HTTPS address to return you to, so it returns you here — and this page hands the authorization to the collector on your own machine.

This page is static. It is plain HTML served from GitHub Pages with no server-side code, no analytics, and nothing loaded from any other host. The authorization code is read by script in your own browser and goes only where you send it. It is removed from the address bar as soon as it is read, so it does not linger in your browser history.
