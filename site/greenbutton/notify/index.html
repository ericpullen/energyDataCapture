Subscription notifications

energycap · Green Button Connect

This is the notification address registered for energycap's Green Button Connect subscription.

energycap does not rely on push notifications. It polls its subscription on a schedule instead, so no data is missed if a notification is never delivered.

This address is currently served by a static host, which answers GET but not POST. If the data custodian requires a notification endpoint that accepts POST, tell us and one will be provided — see the contact below.

Why polling

The collector runs on a machine inside a home with no public address and no inbound access. Treating notifications as an optimisation rather than a dependency means a missed, delayed, or undeliverable notification cannot turn into a gap in the record — the next scheduled poll picks up whatever has been published.
